# Ledger

MERN Stack Expense & Ledger Management App.

## Features
- JWT Login/Register
- Daily expenses
- Monthly expenses
- Payment/Jama tracking
- Paid / Partial / Pending status
- Date-wise history
- Monthly/category summaries
- React dashboard

## Structure
- `backend` - Express + MongoDB API
- `frontend` - React + Vite UI

## Run

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
